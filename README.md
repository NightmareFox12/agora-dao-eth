# Agora DAO

## 📖 Project Overview

Agora DAO is a **decentralized autonomous organization** platform that enables community‑driven governance, task management, and token‑based incentives. Built on Ethereum (or compatible EVM chains) with a **Hardhat** smart‑contract suite and a **Next.js** front‑end, the Dapp lets users create DAOs, join them, and execute on‑chain actions in a trust‑less manner.

## ✨ Key Features

- **Decentralized Escrow for Task Payments** – Funds are locked in a smart contract until a task is completed and verified, ensuring fair compensation without a trusted third party.
- **Role‑Based Access Control (RBAC)** – Leveraging OpenZeppelin's `AccessControl`, the system defines `ADMIN_ROLE`, `USER_ROLE`, and custom roles to restrict actions such as DAO creation, task submission, and fund withdrawal.
- **DAO Creation & Management** – Users can spin up new DAOs via the `AgoraDaoFactory` contract, specifying name, description, category, and image.
- **Join & Participate** – Members can join a DAO, earn reputation, and interact with on‑chain governance mechanisms.
- **Token & NFT Rewards** – Integrated reward system (tokens/NFTs) for active contributors.

## 🛠️ Installation

```bash

# Install dependencies (using Yarn 3)

# Edit the .env file with your RPC URL and private key
```

## 📦 Usage

1. **Create a DAO** – Navigate to the _Create DAO_ dialog, fill in details, and submit. The transaction deploys a new `AgoraDao` contract.
2. **Join a DAO** – Click _Join DAO_ on the DAO page. Your address is added to the DAO’s member list.
3. **Create a Task** – (Future feature) Submit a task with a reward. Funds are escrowed in the contract.
4. **Complete & Release** – Once the task is marked complete, the escrow releases payment to the assignee.
